# Storm Arcade

Browser arcade games built from Storm Studio weekly content — EL 9–12, Laurel High School.

| Week | Game | Play |
|---|---|---|
| 15 · Soccer, The World's Game | Penalty Shootout + ELPA21 Gallery | [index.html](https://radan55.github.io/Stormarcade/) |
| 15 · Wednesday · Bend It Like Science | 30-minute station run: Listen · Read · Arcade (3 games) · auto-graded Writing · Speak | [week15/wednesday](https://radan55.github.io/Stormarcade/week15/wednesday/) |

No login, no install. Works on Chromebooks and phones. Listening tasks use the browser's read-aloud; Speaking tasks use the microphone (playback in page).
